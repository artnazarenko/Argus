# Architecture intake

This directory will contain the reviewed Argus architecture.

The proposal should describe:

1. component and page hierarchy;
2. expected framework and styling approach, if already decided;
3. Figma library structure and naming conventions;
4. token plugin and exported file format;
5. required Storybook sections;
6. expected browser-preview and publication workflow;
7. boundaries between designer reference code and production code.

No framework choice is recorded until the preliminary architecture is added.
