Сравнение механическое: смена имени режима (`Light` → `ARGUS Light`, `Dark` →
`ARGUS Dark`) также считается изменением. Это не равно количеству осмысленных
визуальных решений.

## Режимы

| Группа | ANT | Argus | Решение для первого Storybook |
| --- | --- | --- | --- |
| Цвета | `Light`, `Dark` | `ARGUS Light`, `ARGUS Dark` | Реализовать оба переключаемых режима. |
| Размеры и типографика | `Default`, `Compact` | `Default`, `Compact` | Использовать `Default`; хранить `Compact` без UI-переключателя. |

## Подтверждённая типографика

Токены `fontFamily` и `fontFamilyCode` в Argus равны `X5 Sans VF` как для
`Default`, так и для `Compact`. До предоставления разрешённого web-шрифта
Storybook должен использовать явно задокументированный временный fallback, а
не подменять семейство молча.

## Практическое правило нормализации

Исходные JSON не редактируются. Следующий шаг создаст отдельные нормализованные
runtime-токены с устойчивыми именами и mapping-документом:

`Figma source path → normalized token → CSS variable → Storybook control`.

Это позволит фронтенд-команде проверить значение, исходный путь и режим темы,
не принимая демонстрационный код Argus за production-реализацию.
