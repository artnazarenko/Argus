# Техническая основа Ant Design

## Назначение

`NEW DS ARGUS` — визуальный и токенный источник истины для этого репозитория.
Ant Design — техническая основа для компонентов, которые в Argus не были
изменены, и источник проверенного React API. Это не означает автоматического
копирования внешнего вида из документации Ant.

## Порядок принятия решений

1. Сначала проверяем опубликованный компонент и варианты в `NEW DS ARGUS`.
2. Затем берём API, доступность и интерактивное поведение из версии `antd`,
   закреплённой в `package.json`.
3. Поверх Ant применяем токены Argus: шрифт X5 Sans VF, цвета, размеры,
   отступы, радиусы, состояния и иконки Lucide.
4. Если в Figma и Ant есть расхождение, в Storybook фиксируем решение и
   вариант Argus. Production-команда самостоятельно решает, как перенести его
   в рабочий код.

## Работа с обновлениями

- Текущая техническая база: `antd ^6.6.2`.
- Перед обновлением зависимости проверяем changelog Ant и матрицы затронутых
  компонентов в Storybook: состояния, размеры, фокус, disabled, RTL/тёмную
  тему, если они применимы.
- Не переносим изменения Ant «вслепую»: визуальная проверка всегда проходит по
  New DS Argus.

## Раскладка

| Инструмент | Когда использовать |
| --- | --- |
| CSS Flex / Ant `Flex` | Одномерные группы: Sidebar + рабочая область, тулбары, фильтры, кнопки, перенос чипов. |
| CSS Grid | Двумерные области: Main Content + Aside, сетка карточек и настраиваемые секции. |
| Ant `Row` / `Col` | Только локальная 24-колоночная сетка внутри Custom-слота: формы, карточки, статистика. |
| `ArgusAppLayout` | Каркас портала: закреплённый Sidebar, диапазоны ширины, независимые вертикальные скроллы и режим Header. |

Для каркаса Argus не используем `Row` / `Col`: ему нужна фиксированная ширина
Sidebar (`232 px`), опциональный Aside (`240 px`), горизонтальная прокрутка
только рабочей области при ширине менее `1280 px` и максимум `1920 px`.
