# Sidebar: контракт для дизайна и фронтенда

Статус: рабочий reference-компонент Storybook, не production-исходник.

## Что проверяется в истории `Shell/Sidebar`

- конфигурация портала Argus и подсистем СУИБ и B2B Антифрод;
- развёрнутый и свёрнутый режимы;
- активный и неактивный пункт навигации;
- переключатель между восемью системами;
- длинное имя пользователя;
- темы `ARGUS Light` и `ARGUS Dark` через общий toolbar Storybook.

## Контракт данных

Sidebar не содержит отдельную копию меню для каждой системы. Он получает
`ApplicationDefinition`: идентификатор, название, знак и массив пунктов
навигации. Канонический стартовый реестр находится в
`src/data/applications.ts`.

Это демонстрационное разделение намеренно: реальный фронтенд может получать
такую конфигурацию из собственного источника, не переиспользуя код Storybook.

## Доступность и поведение

- У кнопок есть доступные названия и tooltip через `title` в свёрнутом режиме.
- `Свернуть` становится `Развернуть меню`.
- При выборе системы dropdown закрывается, а навигация меняется вместе с ней.
- Точное графическое семейство иконок пока заменено нейтральными текстовыми
  знаками: до передачи утверждённого SVG-набора это честнее, чем имитировать
  иконки из Figma.
